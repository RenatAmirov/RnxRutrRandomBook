# Случайная книга RuTracker

Фоновое приложение для Windows 10 и 11. Удерживайте **Ctrl** и нажмите остальные клавиши сочетания так, чтобы все они оказались зажаты одновременно. Можно использовать левый или правый Ctrl. Буквы определяются по расположению клавиш и работают в русской раскладке.

Приложение открывает случайную тему из недавних книжных публикаций RuTracker в Яндекс Браузере.

- **Ctrl+R+N+D** выбирает из общей подборки, в которую входят художественная литература, детские познавательные книги, философия, математика и программирование.
- **Ctrl+I+T** выбирает книгу из раздела [«Компьютерная литература»](https://rutracker.org/forum/viewforum.php?f=1418) и его книжных подразделов.

Перехват полного сочетания предотвращает запуск команд активного окна, например открытие окна Проводника или новой вкладки. При отдельном нажатии **Ctrl** с одной из этих букв команда активного окна срабатывает при отпускании клавиши. Для окон, запущенных от администратора, Windows может блокировать передачу отложенных нажатий.

## Установка

Понадобятся Яндекс Браузер и [Python 3.10 или новее для Windows](https://www.python.org/downloads/windows/). Откройте PowerShell в папке проекта и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Install
```

Установщик запускает приложение без окна и добавляет запуск при входе текущего пользователя через Планировщик заданий. Windows запускает приложение в пользовательском сеансе, где доступны клавиатура и браузер. Если `python` отсутствует в `PATH`, добавьте `-PythonPath 'C:\путь\к\python.exe'` к команде установки.

## Управление

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Start
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Uninstall
```

`Stop` останавливает приложение до следующего ручного запуска или входа в Windows. `Uninstall` удаляет задание автозапуска. После переноса проекта в другую папку повторите установку из новой папки.

При недоступности лент или ошибке запуска Яндекс Браузера приложение подаёт системный звук и записывает ошибку в `%LOCALAPPDATA%\RnxRutrRandomBook\service.log`. Доступность лент можно проверить отдельно командой `python .\book_service.py --url`.
