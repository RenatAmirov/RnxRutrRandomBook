# Случайная книга RusTraker  и DjVu Online

Фоновое приложение для Windows 10 и 11. Удерживайте **Ctrl** или **Alt** и нажмите остальные клавиши сочетания так, чтобы все они оказались зажаты одновременно. Буквы определяются по расположению клавиш и работают в русской раскладке.

Приложение открывает случайную книгу в Яндекс Браузере. Сочетания с **Ctrl** выбирают из недавних книжных публикаций RuTracker.

- **Ctrl+R+N+D** выбирает из общей подборки, в которую входят художественная литература, детские познавательные книги, философия, математика и программирование.
- **Ctrl+I+T** выбирает книгу из раздела [«Компьютерная литература»](https://rutracker.org/forum/viewforum.php?f=1418) и его книжных подразделов.
- **Ctrl+M+A+T** выбирает книгу из раздела [«Математика»](https://rutracker.org/forum/viewforum.php?f=2028).
- **Ctrl+F+I+Z** выбирает книгу из раздела [«Физика»](https://rutracker.org/forum/viewforum.php?f=2026).
- **Ctrl+F+I+L** выбирает книгу из раздела [«Философия»](https://rutracker.org/forum/viewforum.php?f=995).
- **Ctrl+R+E+L** выбирает книгу из раздела [«Вера и религия»](https://rutracker.org/forum/viewforum.php?f=1686) и его книжных подразделов.
- **Alt+R+N+D** выбирает книгу из каталога [DjVu Online](https://djvu.online/latest).
- **Alt+I+T** выбирает случайную книгу на DjVu Online по темам ИТ, компьютеров, программирования, сетей, интернета, ИИ и машинного обучения.
- **Alt+T+A+G** открывает окно ввода тега. Введите тег, например `информационные технологии`, и нажмите **ОК** или **Enter**. Яндекс Браузер откроет список книг с этим тегом. **Esc** закрывает окно ввода.

Если DjVu Online запрашивает проверку браузера, случайная книга выбирается из соответствующей встроенной подборки. Проверку при необходимости можно пройти в открытой вкладке.

Перехват полного сочетания предотвращает запуск команд активного окна, например открытие окна Проводника или новой вкладки. При отдельном нажатии **Ctrl** или **Alt** с одной из букв соответствующего сочетания команда активного окна срабатывает при отпускании клавиши. Для окон, запущенных от администратора, Windows может блокировать передачу отложенных нажатий.

## Установка

Понадобятся Яндекс Браузер и [Python 3.10 или новее для Windows](https://www.python.org/downloads/windows/) с Tcl/Tk для окна ввода тега. Откройте PowerShell в папке проекта и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Install
```

Установщик запускает приложение без окна и добавляет запуск при входе текущего пользователя через Планировщик заданий. Windows запускает приложение в пользовательском сеансе, где доступны клавиатура и браузер. Если `python` отсутствует в `PATH`, добавьте `-PythonPath 'C:\путь\к\python.exe'` к команде установки.

## Управление

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Start
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 Uninstall
```

`Stop` останавливает приложение до следующего ручного запуска или входа в Windows. `Uninstall` удаляет задание автозапуска. После переноса проекта в другую папку повторите установку из новой папки.

При недоступности лент RuTracker или ошибке запуска Яндекс Браузера приложение подаёт системный звук и записывает ошибку в `%LOCALAPPDATA%\RnxRutrRandomBook\service.log`. Доступность лент RuTracker можно проверить отдельно командой `python .\book_service.py --url`.
